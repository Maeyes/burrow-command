# Relic icon atlas

Generated with the built-in imagegen tool. Transparent PNG, 5 columns × 2 rows.
Rows: Dragon Heart, Ruyi Jingu Bang, Excalibur, Gorgon Eye, Fenrir Fang; Heart Scale, Orochi Scale, Vampire Heart, Abyssal Tentacle, Collection chest.
UI uses CSS background positions with nearest-neighbor rendering. Unreleased bosses are covered by a question-mark placeholder in cards and details. Future category tabs are excluded from the rendered archive; collection/save data is retained.

Prompt: One production transparent game icon spritesheet, exactly 5 columns × 2 rows equal square cells, ten centered icons, no text/borders/labels. Crisp detailed fantasy RPG pixel art, hard pixel edges, limited palettes, dark outlines, readable at 48px. Subjects in the row order above; consistent visual size and pixel density, actual alpha transparency.
